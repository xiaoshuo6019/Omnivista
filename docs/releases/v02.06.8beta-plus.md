# v02.06.8beta+ · 生图与算力管理更新

- 新版每份授权默认允许一个有效运行实例，不同授权独立使用。
- 运行许可正常每6小时续期，上次成功核验后最多有效12小时；断网和重连不重置有效期。
- 授权失效后停止接收新任务和新启动，已有任务允许收尾，保留登录、管理、恢复及停止操作。
- 已作废授权码不可重新启用、激活或续期，需要重新申请新码。
- 补齐 v01 的10条默认提示词，并保留个人收藏。
- 反推能力检测独立于其他生图工作流，完善缺少模型或运行组件时的提示。
- 启动器0.1.9增加逐项自检，检查运行环境、模型、工作流、NAS服务、算力凭据和本机后端。
- 完整环境目录与现有配置继续保留；启动器0.1.9可配套7beta NAS使用。
