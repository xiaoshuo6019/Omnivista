# v02.06.5beta · 算力卡片与统一界面优化

## 本次更新

- 算力中心采用紧凑的多电脑卡片，大屏三列、窄屏自适应；只有一台电脑也不再撑满整行。
- 新电脑请求接入时显示统一主题的确认卡片，不再常驻空的待确认面板。
- 优化顶部状态统计，任务运行状态与在线、空闲状态分开显示。
- 界面统一使用“任务”相关文案，更新暂停与恢复任务接收的说明。
- 修复模型版本标识误触折叠，折叠操作独立放在标题右侧。
- 恢复主题选项彩色色点，使用齿轮切换创作与管理，移除模块切换浮动提示；退出登录增加居中卡片确认。
- 管理页与创作页对齐，消除横向滑条，侧栏版本号的 beta 单独换行。
- 更新公开首页的算力中心及创作界面截图。
- 账号页采用管理员、用户卡片、创建/修改三排布局，主题配色统一，专业用户优先排列。
- 登录页采用粉紫渐变大 Logo、半透明卡片，Logo 与表单上下错开、水平居中。
- 启动器升级为 0.1.5，NAS 地址旁显示真实连接状态，窗口和 Windows 文件属性同步版本号。

## 下载与升级

- 本版附件 `omnivista-v02.06.5beta-linux-amd64.tar` 为 x86-64 NAS Docker 镜像，另附 `SHA256SUMS`。
- 镜像：`ghcr.io/xiaoshuo6019/omnivista:v02.06.5beta`，服务端口仍为 `7870`。
- 已安装用户备份数据后，沿用原数据卷、图片目录与端口配置更新容器。导入镜像不会自动替换运行容器。
- `Omnivista-path-0.1.5.zip` 是启动器更新补丁，另附 `SHA256SUMS-launcher`。已有完整环境的电脑退出旧启动器后，仅替换原 EXE，保留运行环境、模型与 `private` 配置。
- 新电脑先到 [base 完整基础环境下载页](https://github.com/xiaoshuo6019/Omnivista/releases/tag/v02.06.4beta)，下载 `Omnivista-base-0.1.4.7z.001`～`.004` 全部四卷，一起解压，再安装本版 path 补丁。base 沿用既有环境，兼容 5beta；模型与显卡驱动需自行准备。
- 下载命名约定：`base` 为首次安装完整环境，`path` 为后续更新包；启动器文件名只带独立版本号，NAS 兼容版本写在说明中。

本次不增加新的生成功能，不修改原基础成图流程。真实 GPU 任务和设备控制仍由用户在自己的环境验证；截图使用演示数据，不代表性能测试结果。
