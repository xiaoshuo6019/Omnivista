# v02.06.4beta · 多算力卡片与配套启动器

## 本版更新

- 首页与管理中心统一导航、账号信息和版本区域；首页右侧按电脑显示紧凑算力卡片，可直接启动、暂停或恢复接单。
- 算力中心采用卡片布局，区分待确认与已接入电脑，提供逐台启动、待机、暂停接单及更多操作。
- 启动器填入 NAS 地址后主动连接，由 Web 确认加入；后续自动重连，Windows 登录后可自动运行启动器，但不自动启动算力。
- 配套启动器新增只读 CPU、内存、首张 NVIDIA GPU/显存与实际模型清单上报；缺失信息明确提示，不加载模型或执行生成测试。
- 模型配置按账号与电脑保存，支持逐台重新检测、手动搭配及推荐；新任务保存配置快照，不改变正在执行的任务。
- Web 远程启动、待机、关机以执行回执为准；破坏性操作二次确认。NAS 提供局域网唤醒设置，发送成功不代表电脑已开机。
- 启动器右侧按钮调整为白底正方形，上方图标、下方“登录”；保留原配置及原有基础成图代码。
- 移除旧管理页面及专用脚本、样式，账号、存储和日志统一使用管理中心；同步修正教程正文与弹框中的旧入口。
- 同版本补包收整算力中心布局，并将 Windows 下载改为包含独立 Python、ComfyUI、必要插件和工作流的完整算力端包；不包含模型与个人配置。

## 下载与升级

- `omnivista-v02.06.4beta-linux-amd64.tar`：NAS Docker 镜像离线包，适用于 x86-64 NAS。
- `Omnivista-base-0.1.4.7z.001`～`.004`：Windows 完整算力端，共 4 卷、约 6.34 GiB，解压后运行环境约 15.6 GiB（模型另备）；独立版本仍为 0.1.4，兼容版本为 v02.06.4beta。下载全部同名分卷到一个目录，用 7-Zip 打开 `.001` 解压。不能只下载首卷，也不能只取出 EXE。
- `SHA256SUMS`：NAS 镜像与 Windows 完整算力端各分卷的 SHA256 校验值。

Docker 镜像：`ghcr.io/xiaoshuo6019/omnivista:v02.06.4beta`。不更新 `latest`。

升级前备份原数据与配置；NAS 使用原持久化目录重新创建容器，端口保持 7870。Windows 完整解压后保留 Omnivista 与 Omnivista_models 同级结构，自行准备模型并配置自己的 NAS 地址。已有用户保留原模型和 private 配置，不能用空目录覆盖原配置。包内包含 Python、PyTorch/CUDA 运行库、ComfyUI、插件和工作流；不包含任何模型、个人凭据或 Windows GPU 驱动。

程序与模型继续分开，启动器选择模型根目录即可。包内“模型清单与路径.md”列出当前基础文生图/编辑所需的 6 个权重（约 11.40 GiB）、用途与分类位置；不代表 v01 全部功能资源。

这是 beta 版本。CI 检查服务逻辑和 Linux 容器启动；真实界面、GPU 生图、远程关机及网络唤醒效果由用户在实际环境验证。Docker bridge 下广播能否到达还取决于 NAS、BIOS 与网卡设置。


## Windows 下载命名

`Omnivista-base-0.1.4.7z.001`～`.004` 是完整基础环境，四卷须全部下载；后续 `Omnivista-path-版本号.zip` 是启动器更新补丁。首次安装先解压 base，再安装最新 path；已有完整环境只更新 path。base 可配合 NAS 5beta 使用，模型与显卡驱动仍需自行准备。仅调整附件名称，完整包内容与摘要未变。
