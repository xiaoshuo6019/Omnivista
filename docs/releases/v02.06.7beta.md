# v02.06.7beta · 生图功能接入

本版配套 NAS 界面 `v02.06.7beta` 与 Windows 启动器 `0.1.7`。NAS、启动器和补丁内七个工作流需要配套更新；模型权重仍由用户自行准备。

## 新增功能

- 替换角色、换头换脸、洗图、姿态控制、扩图进入现有 NAS 队列，支持租约、恢复、取消、真实进度和结果保存。
- 参考图、最多四个 LoRA、4K 像素增强、潜空间二次采样及任务后内存回收会随任务参数发送到算力端。
- 图片反推在算力电脑本地使用 Qwen3-VL，完成后的文本保存在任务记录并写回创作页提示词框。
- 功能按钮按算力电脑实际上报的工作流和模型资产开放；任务调度再次校验模式、LoRA 和放大模型，避免不完整电脑误领任务。
- 管理员可对明确选择的空闲电脑请求清理任务与回执缓存。清理不会触碰模型、工作流、配置或正在运行的任务。

## 界面与账号

- 任务详情再次点击即可收起，关闭卡片不会取消任务。
- 账号编辑保持原卡片宽度，紧凑向下展开；支持设置昵称，侧边栏优先显示昵称。
- 欢迎词半透明显示，画廊有图片时仍可见，图片操作保持可用。

## Windows 升级

1. 完全退出旧启动器和托盘进程，备份旧 EXE。
2. 将 `Omnivista Compute Launcher 0.1.7.exe` 放入原 Omnivista 根目录，并更新桌面快捷方式。
3. 备份原 `workflows` 目录中的同名文件，再复制补丁内七个工作流。不要删除目录中的其他工作流。
4. 保留 `app`、`runtime`、`private`、`cache`、`logs` 和模型目录；本补丁不是完整 base。
5. 先更新 NAS，再启动 0.1.7；到创作页确认各功能是否按本机资产正确开放。

## 模型与能力

- 替换角色需要 `bfs_body_swap_v1.0_qwen_2.1.safetensors`。
- 换头换脸需要 `bfs_head_v1_qwen_2.1.safetensors`。
- 扩图需要 `qwen-image-2.1-outpaint-v2.safetensors`。
- 4K 增强默认需要 `4x-ClearRealityV1_Soft.safetensors`。
- 图片反推需要 Qwen3-VL-4B GGUF、对应 mmproj 和兼容的 `llama_cpp` 运行组件。
- 各工作流模板内原有 LoRA 也必须存在；缺少任一实际依赖时，启动器不会广告该模式。

## 验证边界

本版源码通过静态检查、逻辑测试和隔离无头浏览器回归。浏览器测试使用临时 NAS 数据库和模拟任务，不访问生产 NAS，也不运行真实 GPU 推理。发布镜像由自动构建流程生成并执行 Linux 容器启动/重启检查；真实模型端到端与 GPU 推理不在本次验收范围。
